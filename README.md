# MOEX History Daily Downloader

Скрипт для скачивания полной дневной истории торгов по всем инструментам выбранного рынка Московской биржи через [ISS MOEX API](https://iss.moex.com/iss/reference/).  
Требуется действующая подписка на доступ к историческим данным ISS.

## Возможности

- Сбор подневных данных за любой диапазон дат (например, с 2000 года по 2026).
- Автоматическая пагинация для дней с большим количеством записей.
- Сохранение промежуточных результатов по годам во временные CSV‑файлы (`temp_moex_history_ГГГГ.csv`).
- Объединение всех данных в итоговый CSV (и опционально в Parquet).
- Восстановление после обрыва: при повторном запуске уже скачанные годы загружаются из временных файлов.
